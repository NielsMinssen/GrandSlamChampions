# 👉 [nielsminssen.github.io/GrandSlamChampions](https://nielsminssen.github.io/GrandSlamChampions/)

Les vainqueurs des tournois du Grand Chelem de tennis, mis à jour chaque semaine par un workflow GitHub Actions
([.github/workflows/main.yml](.github/workflows/main.yml)) qui scrape les résultats, les agrège et optimise les images.
